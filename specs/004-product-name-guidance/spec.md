# Feature Specification: คำแนะนำการตั้งชื่อสินค้าให้ชัดเจน

**Feature Branch**: `004-product-name-guidance`

**Created**: 2026-09-11

**Status**: Draft

**Input**: User description: "เปลี่ยนชื่อ Product Name ของสินค้า ให้ชัดเจน เช่น เงาะ"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - ผู้ดูแลระบบเห็นคำแนะนำการตั้งชื่อเมื่อเพิ่ม/แก้ไขสินค้า (Priority: P1)

เมื่อผู้ดูแลระบบเปิดฟอร์ม "เพิ่มสินค้า" หรือ "แก้ไขสินค้า" ในหน้าจอสต็อกสินค้า ช่องกรอกชื่อสินค้าจะแสดงตัวอย่างและคำแนะนำให้ตั้งชื่อสินค้าแบบเจาะจง (เช่น "เงาะ", "มะม่วง") แทนการตั้งชื่อแบบกว้าง ๆ หรือคลุมเครือ (เช่น "ผลไม้", "สินค้า 1") เพื่อให้พนักงานขายและระบบค้นหาสินค้าได้ง่ายและแม่นยำขึ้น

**Why this priority**: เป็นความต้องการหลักที่ผู้ใช้ระบุมาโดยตรง ชื่อสินค้าที่คลุมเครือทำให้พนักงานค้นหาสินค้าบนหน้าขาย (ค้นหาด้วยชื่อ) ผิดพลาดหรือสับสนได้ ฟีเจอร์นี้เป็นการปรับปรุงเล็กที่ให้คุณค่าได้ทันทีโดยไม่ต้องแก้ไขข้อมูลสินค้าที่มีอยู่แล้ว

**Independent Test**: เข้าสู่ระบบด้วยบัญชี Admin เปิดหน้าจอสต็อกสินค้า กดปุ่ม "เพิ่มสินค้า" และตรวจสอบว่าช่องชื่อสินค้าแสดงตัวอย่าง/คำแนะนำการตั้งชื่อที่ชัดเจน จากนั้นเปิดแก้ไขสินค้าที่มีอยู่แล้วและตรวจสอบว่าคำแนะนำแสดงผลเช่นเดียวกัน

**Acceptance Scenarios**:

1. **Given** ผู้ดูแลระบบเปิดฟอร์ม "เพิ่มสินค้า" และช่องชื่อสินค้ายังว่างอยู่, **When** ดูที่ช่องชื่อสินค้า, **Then** ระบบแสดงตัวอย่างชื่อสินค้าที่ชัดเจน (เช่น "เงาะ") เป็น placeholder ในช่องกรอก
2. **Given** ผู้ดูแลระบบเปิดฟอร์ม "เพิ่มสินค้า" หรือ "แก้ไขสินค้า", **When** ดูใต้ช่องชื่อสินค้า, **Then** ระบบแสดงข้อความคำแนะนำสั้น ๆ อธิบายว่าควรตั้งชื่อสินค้าให้เจาะจง (ระบุชนิด/พันธุ์ที่ชัดเจน) แทนคำกว้าง ๆ ไม่ว่าช่องนั้นจะมีค่าอยู่แล้วหรือไม่ก็ตาม
3. **Given** ผู้ดูแลระบบเปิดฟอร์ม "แก้ไขสินค้า" ของสินค้าที่มีชื่ออยู่แล้ว (เช่น "ผลไม้1"), **When** ฟอร์มโหลดขึ้นมา, **Then** ช่องชื่อสินค้าแสดงค่าชื่อเดิมตามปกติ และข้อความคำแนะนำใต้ช่องยังคงแสดงอยู่เพื่อชวนให้แก้ไขชื่อให้ชัดเจนขึ้นหากต้องการ
4. **Given** ผู้ดูแลระบบพิมพ์ชื่อสินค้าใด ๆ ในช่องนี้ (ไม่ว่าจะเจาะจงหรือกว้าง ๆ), **When** กดบันทึก, **Then** ระบบบันทึกชื่อสินค้าตามที่พิมพ์ได้ตามปกติ โดยไม่ปฏิเสธหรือแจ้งข้อผิดพลาดใด ๆ จากคำแนะนำนี้ (คำแนะนำเป็นเพียงการชี้แนะ ไม่ใช่การบังคับ)

---

### Edge Cases

- สินค้าที่มีอยู่แล้วในระบบด้วยชื่อคลุมเครือ (เช่น "ผลไม้1") จะไม่ถูกเปลี่ยนชื่อให้อัตโนมัติ — คำแนะนำนี้ช่วยเฉพาะตอนที่ผู้ดูแลระบบเพิ่มสินค้าใหม่หรือเข้ามาแก้ไขสินค้านั้นเองเท่านั้น
- ผู้ดูแลระบบลบข้อความในช่องชื่อสินค้าจนว่างระหว่างแก้ไข — placeholder ตัวอย่างจะกลับมาแสดงตามพฤติกรรมมาตรฐานของช่องกรอกข้อความ
- ความยาวหรือกฎอื่น ๆ ของชื่อสินค้าที่มีอยู่เดิมในระบบ (เช่น ความยาวสูงสุด) ไม่เปลี่ยนแปลงจากฟีเจอร์นี้

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: ฟอร์ม "เพิ่มสินค้า" ในหน้าจอสต็อกสินค้าต้องแสดงตัวอย่างชื่อสินค้าที่ชัดเจน (เช่น "เงาะ") เป็น placeholder ในช่องกรอกชื่อสินค้าเมื่อช่องนั้นยังว่างอยู่
- **FR-002**: ทั้งฟอร์ม "เพิ่มสินค้า" และ "แก้ไขสินค้า" ต้องแสดงข้อความคำแนะนำสั้น ๆ ใกล้ช่องชื่อสินค้า อธิบายว่าควรตั้งชื่อสินค้าให้เจาะจง/ระบุชนิดที่ชัดเจน แทนการใช้คำกว้าง ๆ หรือคลุมเครือ
- **FR-003**: คำแนะนำและตัวอย่างตาม FR-001/FR-002 ต้องแสดงผลโดยไม่ต้องมีการคลิกหรือโต้ตอบเพิ่มเติมจากผู้ดูแลระบบ (แสดงทันทีที่ฟอร์มเปิดขึ้น)
- **FR-004**: ระบบต้องไม่บังคับหรือปฏิเสธการบันทึกชื่อสินค้าใด ๆ อันเนื่องมาจากคำแนะนำนี้ — ผู้ดูแลระบบยังสามารถตั้งชื่อสินค้าเป็นอะไรก็ได้ตามเดิม (คำแนะนำเป็นการชี้แนะเชิง UX เท่านั้น ไม่ใช่กฎ validation ใหม่)
- **FR-005**: ฟีเจอร์นี้ต้องไม่เปลี่ยนแปลงชื่อสินค้าที่มีอยู่แล้วในระบบโดยอัตโนมัติ ไม่มีการแก้ไขข้อมูลย้อนหลัง

### Key Entities

ฟีเจอร์นี้ไม่มีการเพิ่ม/แก้ไขเอนทิตีข้อมูลใด ๆ — ใช้ฟิลด์ชื่อสินค้า (`Product.Name`) ที่มีอยู่แล้วในระบบ (มีอยู่ตั้งแต่ 001-pos-system) โดยไม่เปลี่ยนแปลงรูปร่างหรือกฎของข้อมูล

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ทุกครั้งที่ผู้ดูแลระบบเปิดฟอร์มเพิ่มหรือแก้ไขสินค้า คำแนะนำและตัวอย่างการตั้งชื่อจะปรากฏให้เห็นทันทีโดยไม่ต้องคลิกหรือเลื่อนหน้าจอเพิ่มเติม
- **SC-002**: ผู้ดูแลระบบที่ไม่เคยใช้ระบบมาก่อนสามารถเข้าใจได้ภายใน 5 วินาทีแรกที่เห็นฟอร์มว่าควรตั้งชื่อสินค้าอย่างไรให้ชัดเจน โดยไม่ต้องอ่านเอกสารหรือคู่มือเพิ่มเติม
- **SC-003**: การเพิ่ม/แก้ไขสินค้าที่มีอยู่เดิมทั้งหมดยังคงทำงานได้ตามปกติ 100% หลังเพิ่มฟีเจอร์นี้ (ไม่มีการปฏิเสธการบันทึกชื่อสินค้าใด ๆ ที่ไม่เคยถูกปฏิเสธมาก่อน)

## Assumptions

- คำแนะนำนี้เป็นการ "ชี้แนะ" (guidance) ผ่าน UI เท่านั้น ไม่ใช่การเพิ่มกฎ validation บังคับความเจาะจงของชื่อสินค้า — สอดคล้องกับที่ผู้ใช้เลือกขอบเขตนี้ไว้ชัดเจน (ไม่ต้องการให้ระบบปฏิเสธชื่อสินค้าที่ไม่ชัดเจน)
- ป้ายชื่อฟิลด์ (label) ของฟอร์มเพิ่ม/แก้ไขสินค้าคงรูปแบบเดิมของ UI ปัจจุบัน (ภาษาอังกฤษ เช่น "Name") ส่วนตัวอย่างชื่อสินค้าที่ใช้ประกอบคำแนะนำจะเป็นชื่อสินค้าจริงตามภาษาที่ใช้ในร้าน (ภาษาไทย เช่น "เงาะ", "มะม่วง") เนื่องจากเป็นตัวอย่างข้อมูลจริงของร้าน ไม่ใช่ข้อความ label ของระบบ
- ฟีเจอร์นี้ใช้เฉพาะกับช่องชื่อสินค้า (Product Name) ในหน้าจอสต็อกสินค้าเท่านั้น ไม่เกี่ยวกับชื่อฟิลด์อื่น ๆ ในระบบ (เช่น ชื่อพนักงาน ชื่อสมาชิก)
- ตัวอย่างชื่อสินค้าที่แสดงเป็นค่าคงที่ที่กำหนดไว้ล่วงหน้า (ไม่ได้ดึงจากสินค้าจริงในฐานข้อมูล) เพื่อความเรียบง่ายและไม่ต้องพึ่งพาข้อมูลที่อาจไม่มีอยู่ในบางร้าน
