# TaladPOS — เอกสารอธิบาย Logic หน้าจัดการสต็อกสินค้า (Stock Management)

เอกสารชุดนี้อธิบายหน้า `/stock` ที่แอดมินใช้เพิ่ม/แก้ไข/ปิดการขายสินค้า ครอบคลุมตั้งแต่หน้าจอ, API,
กติกาทางธุรกิจ (การอัปโหลดรูป, ความเป็นเอกลักษณ์ของบาร์โค้ด, soft-delete) ไปจนถึงตารางฐานข้อมูล
โดยอ้างอิงจากซอร์สโค้ดจริง ณ วันที่จัดทำเอกสาร (2026-09-11)

## สรุปสั้น (TL;DR)

- หน้านี้อยู่ที่ route `/stock` (`web/src/app/(app)/stock/page.tsx`) และ **จำกัดเฉพาะ Role Admin**
  เท่านั้น — มีการ์ดกันสองชั้น (ฝั่งหน้าเว็บ redirect ออกถ้าไม่ใช่ Admin, ฝั่ง API มี
  `[Authorize(Policy = "Admin")]` บังคับอีกชั้น)
- หน้า Stock ต่างจากหน้า Sales ตรงที่ดึงสินค้าด้วย `includeInactive=true` เสมอ — แอดมินจึงเห็นสินค้าที่
  ปิดขายไปแล้วด้วย ขณะที่หน้าขายสินค้าจะไม่แสดงสินค้ากลุ่มนี้เลย
- การลบสินค้าเป็น **soft-delete** (`Product.Deactivate()` ตั้ง `IsActive = false`) ไม่ใช่การลบแถวจริง
  เพื่อไม่ให้ประวัติการขาย (`SalesOrderLine`) ที่อ้างอิงสินค้านั้นเสียหาย
- บาร์โค้ดต้องไม่ซ้ำกัน บังคับ **สองชั้น**: ตรวจสอบระดับแอป (error message อ่านง่าย) + unique partial
  index ระดับฐานข้อมูล (การันตีจริงแม้มี request ชนกัน)
- รูปสินค้าเก็บเป็นไฟล์บนดิสก์ (`wwwroot/product-images/`) ไม่ได้เก็บเป็น binary ในฐานข้อมูล
  คอลัมน์ `ImageUrl` เก็บแค่ path สัมพัทธ์
