## สรุปสั้น (TL;DR)

- หน้าขายสินค้าอยู่ที่ route `/sales` (`web/src/app/(app)/sales/page.tsx`)
- ราคาสุทธิของตะกร้า **คำนวณที่ฝั่ง Backend เสมอ** ผ่าน `SalesOrderPricingService.Calculate(...)`
  (`api/src/TaladPOS.Domain/Pricing/SalesOrderPricingService.cs`) — ฝั่งหน้าเว็บไม่มีการคำนวณส่วนลดเอง
  เพื่อป้องกันตัวเลขที่แสดงตอน preview กับตอน checkout จริงไม่ตรงกัน
- โปรโมชั่นมี 3 ขอบเขต (Scope): `PerProduct`, `WholeBill`, `MemberDiscount` และคำนวณแบบ **ลดต่อเนื่อง
  (sequential discount)**: ส่วนลดสินค้า/ทั้งบิลหักออกจากยอดก่อน แล้วส่วนลดสมาชิกจึงคำนวณจากยอดที่เหลือ
- ตารางหลักที่เกี่ยวข้อง: `Products`, `Promotions`, `Members`, `Staff`, `SalesOrders`, `SalesOrderLines`
